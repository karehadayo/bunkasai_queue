初回セットアップ

Firebaseの設定を貼り付けてください

このサイトは、複数の端末でデータを共有するために無料のFirebase(Googleのサービス)を使います。
まだ準備がまだの場合は、下の「セットアップ手順を見る」ボタンから作成してください(5分程度で終わります)。

Firebaseの「firebaseConfig」をそのまま下に貼り付けてください。


セットアップ手順(初回のみ・所要5分)

  1. Firebase コンソールを開き、Googleアカウントでログインする
  2. 「プロジェクトを作成」→ 名前を適当に入力(例: bunkasai-queue)→ 作成
  3. 作成後、左メニューの「構築」→「Realtime Database」を選び、「データベースを作成」
  4. ロケーションは任意のもので進み、セキュリティルールは「テストモードで開始」を選ぶ
    (※文化祭当日限定の一時利用のため。ルールは後述の通り期限付きにできます)
  5. 左メニューの「プロジェクトの概要」の歯車アイコン →「プロジェクトの設定」を開く
  6. 下の方の「マイアプリ」で「​</>（ウェブ）」のアイコンをクリックし、アプリを登録(名前は何でもOK)
  7. 表示された firebaseConfig = {"{"} ... {"}"} の中身をコピーし、上のテキストエリアに貼り付けて「保存して始める」を押す

※ Realtime Databaseの「ルール」タブで、下記のように設定しておくと、期間限定で読み書きできるようになり安全です(数字は好きな日付に変更してください)。 

{
  "rules": {
    ".read": "now < 1735689600000",
    ".write": "now < 1735689600000"
  }
}
